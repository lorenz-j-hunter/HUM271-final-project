# Team Contract

##### The contract specifies rules for pushing, commit-making, and task completion

###### Rule 1

Code is only written when it explicitly and clearly relates to an issue on GitHub Actions.

###### Rule 2

To work on an issue, you promise to create a branch for it. The branch name should be the name of the issue
in lower snake case, all low caps.

When you complete the issue, push it and merge it yourself from the terminal instead of creating a
pull request.

###### Rule 3

Complete all that you were assigned to do.

###### By signing this, you promise to fulfill all rules and get the priveledge of working on this.
