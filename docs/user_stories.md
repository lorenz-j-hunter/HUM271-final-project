## *A Note.*
    With regards to unit testing, we use the [Arrange, Act, Assert (AAA)](https://www.tftus.com/blog/what-is-unit-testing-in-software-testing) paradigm. Each user story has three test steps, and these correspond to the steps
of the AAA paradign in that order.

    User stories that are deemed the most central to the experience of the most users (such as adding the main page) receive higher priority; niche uses and
features that represent a small number of users have the least priority. Also, user stories which are both difficult to construct and are not central to the
design concept would receive a low priority. On the other hand, simple user stories which reference the design concept will receive high priority.

    Estimates detail the predicted time of completion and the number of people expected to work on the assignment in question.
